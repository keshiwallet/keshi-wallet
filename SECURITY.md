# Security

Found a problem in Keshi? Thank you. Please tell us privately first.

**Write to contact@keshiwallet.com** with the subject "Security". Please include:

- what you found and why it matters
- the Keshi version (shown in Settings) and your browser
- the steps to reproduce it

Please do not post details of a weakness in a public issue before we have had a chance to fix it.

**Never send a recovery phrase, a private key or a password**, not even a test one that
holds real funds. Nobody from Keshi will ever ask you for one. If someone does, it is a scam.

We read every report and answer as soon as we can. There is no bug bounty yet.

Keshi has not been audited by an independent company yet. Reading the code and telling us
what you find is the most useful help you can give.
